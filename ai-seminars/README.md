# AI Seminars

One short slide deck per AI seminar. The series moves from generative AI (how it works, the current tools, when to use it and how to check its output) to machine learning (modeling basics, supervised and unsupervised methods, and the current tool landscape).

Each deck has:

- a title slide
- up to three content slides of brief bullets, each with **speaker notes** to review and edit
- a closing **Discussion** slide with one practical question that asks students to draw on their own experience and career

## Applying an organization template

The decks use the same plain format as the other seminar decks (black background, white Arial text, **Title Slide** and **Title and Content** layouts, all text in placeholders). See the [technical seminars README](../technical-seminars/README.md) for how to apply an organization's slide master.
