# Technical Seminars

One short slide deck per technical seminar. Each seminar teaches the skill that week's lab needs, from relational database basics through SQL, then scikit-learn and TensorFlow.

Each deck has:

- a title slide
- 8–9 content slides of brief bullets (some with a short code example), each with **speaker notes** to review and edit
- a closing slide with an overview of the matching lab

## Applying an organization template

The decks are deliberately plain (black background, white Arial text) so they can take an organization's slide master later:

- Every slide uses one of two layouts named like the Office defaults: **Title Slide** and **Title and Content**.
- All slide text sits in the layout's title and body placeholders. There are no free-floating text boxes, shapes or images.
- Styling (colors, fonts, sizes) is set on the layouts, not on the slides. The only slide-level formatting is the monospace font on code examples and slightly smaller text on the lab overview slide.

To apply a template in PowerPoint, open a deck, go to **Design → Browse themes** (or paste the slides into a deck built from the template using **Use Destination Theme**), then use **Home → Reset** on the slides if any formatting carries over.
