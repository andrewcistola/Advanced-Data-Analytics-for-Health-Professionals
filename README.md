# Health-Data-Analytics
This repo includes code and content for an intermediate, graduate-level course in health data analytics.

## Contents

| Folder | What it is |
|---|---|
| [`labs/`](labs/) | Thirteen labs, from SQL basics to machine learning, each with a student handout, a full SQL/Python solution and expected results. |
| [`software-setup/`](software-setup/) | Student setup guide for the software (all free and open source): DuckDB, DBeaver Community, and JupyterLab via Miniforge. Includes the conda environment, a setup checker, and a getting-started notebook. |
| [`synthetic-data/`](synthetic-data/) | Generator for the course's synthetic health data warehouse: beneficiaries, monthly coverage, medical and pharmacy claims (2021–2025), prior authorizations, care management, and a hospital payment ledger. Outputs a DuckDB database and Parquet files. |
