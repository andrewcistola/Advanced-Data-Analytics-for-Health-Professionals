# Lab Slides

[`lab_instructions.pptx`](lab_instructions.pptx) presents all thirteen labs in one deck (36 slides):

- **Introduction:** how the labs work, the data, software setup, and the four phases of labs
- **Each lab:** an overview slide (business question, skills, tool and time, data) and an instruction slide (tasks, the AI step, and the deliverable)
- **Wrap-up:** tips that apply to every lab

The slides condense each lab's handout. The full handout (`README.md` in each lab folder) has the exact definitions, code lists and starter code.
